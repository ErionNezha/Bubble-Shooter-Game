# Bubble Shooter Game (Python)

Lojë Bubble Shooter në Python (pygame) — qëllo flluskat, kombino 3+ me të njëjtën ngjyrë për t'i plasur, me muzikë dhe efekte zanore.

`Python` `pygame`

## 🚀 Live Demo
Hape **`index.html`** në browser — demo-ja ekzekutohet direkt, pa instalime.
Nëse repo është publikuar me GitHub Pages: `https://erionnezha.github.io/Bubble-Shooter-Game/`

## 📝 Kodi Burim
Kodi i plotë është në dosjen [`original/`](original/) dhe shfaqet krahas demo-s live në `index.html`.

## ▶️ Ekzekutimi origjinal
Instalo `pip install pygame` dhe ekzekuto `python bubbleshooter.py`.
